# Security Policy

This policy covers all public repositories under the RegistrumUK organisation.

## Reporting a Vulnerability

If you discover a security vulnerability in any RegistrumUK repository,
please report it privately rather than opening a public GitHub issue.

**Email:** security@registrum.co.uk

Please include as much detail as possible: steps to reproduce, affected
repository/version, and potential impact. We aim to acknowledge reports
within 2 business days and will keep you updated as we investigate and fix
the issue.
